# RAAVAN KA DIWALI SET — the villain takes the mic (Suno-ready)

> Concept: Diwali party mein sabse unexpected guest — Lanka ka raja khud. Har saal jalaya jaata hai, har saal wapas aata hai, kyunki uske bina Diwali ka plot hi nahi. Veena wala, Shiv-bhakt, dus dimaag wala — swagger bhi, sach bhi. Villain ki aawaaz se hero ki jeet aur bhi badi lagti hai.

## Style prompt (Suno "Style of Music")
```
dark cinematic Hinglish hip-hop meets bhangra, deep baritone male rap verses, epic sung chorus with crowd, rudra veena riff + dhol + 808 + brass, villain swagger turning gracious, 92 BPM half-time with double-time drop
```

## Suno tips
- Verses rap, chorus sung — style prompt mein "rap verses, sung chorus" explicit hai; agar Suno sab gaa de, verses ko `[Rap Verse 1]` tag karo.
- Veena riff ke liye kabhi-kabhi "sitar" likhna zyada reliable hota hai Suno mein — fallback: `sitar riff` in style.
- Villain tone chahiye par mocking nahi — Jai Shri Ram line Raavan ki *haar maanne* ki hai, uska mazaak nahi.
